How embedding works

1. Load the script once

<script type="module"
  src="https://cdn.jsdelivr.net/gh/sankshitpandoh/asciiiii@main/dist/ascii-art.min.js">
</script>

2. Drop in a tag

<!-- convert any image on the fly -->
<ascii-art src="/me.jpg" cols="90" color animate="flicker"></ascii-art>

<!-- or paste prebuilt art from the Embed tab -->
<ascii-art animate="wave">
  <script type="application/json">{…}</script>
</ascii-art>

3. Style it like text

ascii-art {
  --ascii-font-size: 8px;
  --ascii-fg: #7ee787;
  --ascii-bg: transparent;
}

Animations pause off-screen and respect prefers-reduced-motion. Also available from JavaScript: import { imageToAscii } from 'asciiiii'.
